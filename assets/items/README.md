# Iconos de objetos y equipo

Sube los iconos del equipo aquí. El juego carga automáticamente un PNG con fondo transparente usando el identificador exacto del objeto.

- Formato: PNG con transparencia.
- Tamaño recomendado: 256 × 256 px.
- El objeto debe estar centrado y dejar margen alrededor.
- Estilo: pixel art oscuro, contorno definido y lectura clara en tamaño pequeño.

Abre esta carpeta → **Add file → Upload files** → arrastra los PNG → **Commit changes** en `main`. Puedes subirlos poco a poco. Los que falten conservan un icono provisional.

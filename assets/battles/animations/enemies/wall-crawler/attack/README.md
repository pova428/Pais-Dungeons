# Enemigo · wall-crawler · Ataque

Sube aquí los tres fotogramas del ataque de este enemigo:

- `frame-01.png` — prepara el movimiento.
- `frame-02.png` — impacto o contacto.
- `frame-03.png` — recuperación.

PNG transparente de 512 × 512 px o 512 × 640 px. Mantén el mismo lienzo, tamaño, escala y línea de suelo en los tres archivos. El enemigo debe mirar hacia la izquierda.

El juego reproduce los tres fotogramas automáticamente y añade sacudida, destello y efecto de impacto.

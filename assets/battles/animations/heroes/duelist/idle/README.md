# Salim — respiración idle

- `frame-01.png`: postura neutra.
- `frame-02.png`: inspiración.
- `frame-03.png`: espiración.

PNG RGBA transparente de 512 × 512 px. Mantén los pies en la misma línea y el personaje mirando hacia la derecha. El juego muestra cada frame durante aproximadamente un segundo y repite el ciclo de tres segundos. Al atacar o recibir daño, la animación idle se oculta temporalmente.

No uses GIF ni spritesheet: el juego espera tres PNG independientes con estos nombres exactos.

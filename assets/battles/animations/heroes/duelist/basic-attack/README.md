# Salim — ataque básico

Secuencia del ataque básico de Salim. Usa tres PNG:

1. `frame-01.png` — preparación.
2. `frame-02.png` — impacto.
3. `frame-03.png` — recuperación.

PNG RGBA transparente de 512 × 512 px, personaje mirando hacia la derecha y con la misma escala y línea de suelo en los tres fotogramas. El juego muestra la secuencia en orden y genera por separado el brillo, la sacudida y los números de daño.

# Recursos gráficos de los combates

Esta carpeta contiene los recursos que se mostrarán en el campo de batalla.

- `backgrounds/`: una imagen de fondo por localización.
- `enemies/`: una imagen PNG por tipo de enemigo.

No subas los archivos en la raíz de `assets`: cada imagen debe ir en su subcarpeta y conservar exactamente el nombre indicado en las guías.

## Cómo subir imágenes

1. En GitHub abre `assets/battles/backgrounds` o `assets/battles/enemies`.
2. Pulsa **Add file → Upload files**.
3. Arrastra las imágenes a la ventana.
4. Comprueba que los nombres coinciden con la guía.
5. Pulsa **Commit changes** en la rama `main`.

El juego conserva el escenario provisional cuando una imagen no existe todavía. Puedes subirlas poco a poco; no hace falta tenerlas todas.

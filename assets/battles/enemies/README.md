# Sprites de enemigos

Sube aquí las imágenes de los enemigos en **PNG con fondo transparente**. Recomendación: 512 × 512 px o 512 × 640 px, con el monstruo centrado y los pies dentro de la imagen. El juego aplica una presentación pixelada.

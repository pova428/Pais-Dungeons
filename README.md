# THE FIVE — La Maldición

Primera versión del proyecto: pantalla de título de un RPG táctico de fantasía oscura.

## Qué incluye

- Menú principal a pantalla completa.
- Escenario original de fantasía oscura en pixel art vectorial.
- Diálogo introductorio al seleccionar «Nueva partida».
- Panel de opciones con contraste sombrío y movimiento reducido.
- Créditos.
- Diseño adaptable a escritorio y móvil.
- Preferencias guardadas localmente en el navegador.

## Probar en local

Abre `index.html` en un navegador moderno. No necesita instalación ni dependencias de JavaScript.

## Publicar con GitHub Pages

En el repositorio, abre **Settings → Pages** y selecciona:

- **Build and deployment:** Deploy from a branch
- **Branch:** main
- **Folder:** / (root)

Guarda los cambios. GitHub Pages publicará el contenido del repositorio cuando finalice el despliegue.

## Estructura

- `index.html`: pantalla de título y diálogos.
- `styles.css`: dirección visual, animaciones y adaptación responsive.
- `game.js`: interacciones del menú y preferencias.
- `assets/ashen-keep.svg`: escenario original del bastión en ruinas.

## Dirección artística

La pantalla se plantea como un menú de videojuego, no como una web corporativa: escenario dominante, siluetas, paleta limitada, contraste fuerte, ornamentación discreta y controles integrados en el mundo. Es una interpretación original de fantasía oscura y no utiliza ilustraciones ni recursos de Darkest Dungeon.
